# :triangular_flag_on_post:Level1-Level2 :Write-up


## Challenge Description 
- The password for the next level is stored in a file called "-" located in the home directory


## Solution
- First, we log into `bandit1` using the credentials we got from the previous level

```
┌──(sage㉿S3rp3nt)-[~]
└─$ ssh bandit1@bandit.labs.overthewire.org -p 2220
                         _                     _ _ _   
                        | |__   __ _ _ __   __| (_) |_ 
                        | '_ \ / _` | '_ \ / _` | | __|
                        | |_) | (_| | | | | (_| | | |_ 
                        |_.__/ \__,_|_| |_|\__,_|_|\__|
                                                       

                      This is an OverTheWire game server. 
            More information on http://www.overthewire.org/wargames

backend: gibson-0
bandit1@bandit.labs.overthewire.org's password:
```
- After login, we list the content of our current working directory which is in the home directory `(~)`
```
bandit1@bandit:~$ ls -l
total 4
-rw-r----- 1 bandit2 bandit1 33 Sep 26 21:54 -
```
- As per the challenge description, we find that there is a file called -
- Now, using `cat` command, we are going to read the content of the said file.
  - The `./` means we are opening a file in the current working directory.
```
bandit1@bandit:~$ cat ./-
FLAG IS REDACTED
```

## :bulb:Lessons & Tips
- Learn how to open files with weird filenames.
