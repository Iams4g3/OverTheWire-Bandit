# :triangular_flag_on_post:Level2-Level3 :Write-up


## Challenge Description 
- The password for the next level is stored in a file called --spaces in this filename-- located in the home directory


## Solution
- First, we log into `bandit2` using the credentials we got from the previous level

```
┌──(sage㉿S3rp3nt)-[~]
└─$ ssh bandit2@bandit.labs.overthewire.org -p 2220
                         _                     _ _ _   
                        | |__   __ _ _ __   __| (_) |_ 
                        | '_ \ / _` | '_ \ / _` | | __|
                        | |_) | (_| | | | | (_| | | |_ 
                        |_.__/ \__,_|_| |_|\__,_|_|\__|
                                                       

                      This is an OverTheWire game server. 
            More information on http://www.overthewire.org/wargames

backend: gibson-0
bandit2@bandit.labs.overthewire.org's password:
```
- After login, we list the content of our current working directory which is the home directory `(~)`
```
bandit2@bandit:~$ ls -l
total 4
-rw-r----- 1 bandit3 bandit2 33 Sep 26 21:54 --spaces in this filename--
```
- As per the challenge description, we find that there is a file called --spaces in this filename--
- Now, using `cat` command, we are going to read the content of the said file.
```
bandit2@bandit:~$ cat ./--spaces\ in\ this\ filename-- 
FLAG IS REDACTED
```

## :bulb:Lessons & Tips
- Learn how to open files with weird filenames.
- Learn to use `tab` on your keyboard while typing commands and filenames. This can save you time and prevent typos
