# OverTheWire-Bandit
This is my write-up for the Bandit category of the wargame offered by [OvertheWire](https://overthewire.org)

## Introduction
Bandit-OvertheWire is a wargame which is aimed at absolute beginners. It teaches the basics which in one way or another can help with solving other wargames and CTF challenges out there. Mainly, it focuses on Linux/Unix Basics. The games is organized in levels. You start from Level 0 and you progress by beating each level. Finishing a level will result in information on how to start the next level.

## Prerequisites
1. A computer with internet connection
2. Access to Linux/Unix Terminal
   - **Bare-Metal Linux Operating System** (My Recommendation)
   - **Linux Virtual Machine** (Good choice if you want to play it safe and try Linux)
   - **MacOS** (MacOS terminal commands are mostly the same as Linux for everyday tasks)
   - **Windows Subsystem for Linux-WSL** (A good choice as well)
3. Patience and Willingness to Learn and explore (you will learn more stuff as you go. That's why you are here, right?)
