- We can simply try to `cat` every file in this folder until we get the file that has the flag. But what if there are hundreds of files :thinking:?
- To solve this, we use `file` command to all the files. Meaning, we will check the file type of all the files within the directory to see which file might have the flag

- From the above output, you can see that the file `file07` is of the ASCII text file type. which in simple words it is a text file. This has to be the file with the flag.
- printing the content of the said file using `cat`

```
bandit4@bandit:~/inhere$ cat ./-file07
FLAG REDACTED
```



## :bulb:Lessons & Tips
- Use `file` command to determine the type of a file in Linux.
- Linux does not use 'file extension' to determine the kind of file type it is dealing with like Windows do. It has it's own way for file type determination. So, This command can be useful.
