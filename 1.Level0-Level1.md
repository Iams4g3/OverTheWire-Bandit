# :triangular_flag_on_post:Level0-Level1 :Write-up

## Challenge Description 
- The password for the next level is stored in a file called readme located in the home directory.
- Use this password to log into bandit1 using SSH. Whenever you find a password for a level, use SSH (on port 2220) to log into that level and continue the game.

## Solution
- First, we log into `bandit0` using the credentials from [Level0](https://github.com/Iams4g3/OverTheWire-Bandit/blob/main/0.Level0.md)
  - If it's your first time connecting to a remote host using SSH you will receive an authenticity-check stop
  - Famously known as **TOFU** `Trust On First Use`, This is a security model used by SSH
  - When you connect to a remote server for the first time, your local SSH client doesn't know the server's public key
  - So, it cannot automatically verify that the machine you are trying to connect to  is actually OverTheWire's Bandit server and not a Man-in-the-Middle (MitM) attacker impersonating it.
  - But since I am sure of what server I'm trying to access, I can simply proceed
```

- After login, we list the content of our current working directory which is the home directory `(~)`
```
bandit0@bandit:~$ ls -l
total 4
-rw-r----- 1 bandit1 bandit0 438 Sep 26 21:52 readme
bandit0@bandit:~$
```
- As per the challenge description, we find that there is a file named "readme".
- Now, using `cat` command, we are going to read the content of the said file.
```
bandit0@bandit:~$ cat readme
Congratulations on your first steps into the bandit game!!

## :bulb:Lessons & Tips
- Learn how to login using SSH to securely connect to a remote Linux System. SSH is the most widely used and industry standard for Linux remote administration.
- Learn how to view file content using `cat`. As it is very useful when you want to quickly view a text file content.
