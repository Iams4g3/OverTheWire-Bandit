# :triangular_flag_on_post:Level3-Level4 :Write-up


## Challenge Description 
- The password for the next level is stored in a hidden file in the inhere directory.



## Solution
- First, we log into `bandit3` using the credentials we got from the previous level

```
┌──(sage㉿S3rp3nt)-[~]
└─$ ssh bandit3@bandit.labs.overthewire.org -p 2220

                        | |__   __ _ _ __   __| (_) |_

                      This is an OverTheWire game server. 
            More information on http://www.overthewire.org/wargames

backend: gibson-1
bandit3@bandit.labs.overthewire.org's password:
```
- After login, we list the content of our current working directory which is the home directory `(~)`
```
bandit3@bandit:~$ ls -l
total 4
drwxr-xr-x 2 root root 4096 Sep 26 21:53 inhere
```
- As per the challenge description, we find that there is a folder called inhere in the home directory
- We then navigate inside the inhere directory and look for the hidden file using `ls -al` command

```
bandit3@bandit:~/inhere$ ls -al
total 12
drwxr-xr-x 2 root    root    4096 Sep 26 21:53 .
drwxr-xr-x 3 root    root    4096 Sep 26 21:53 ..
-rw-r----- 1 bandit4 bandit3   33 Sep 26 21:53 ...Hiding-From-You

```
- Now, using `cat` command, we are going to read the content of the said file.
```
bandit3@bandit:~/inhere$ cat ./...Hiding-From-You 
FLAG REDACTED
```

## :bulb:Lessons & Tips
- Linux uses a preceeding `.` as a way to hide files.
- It should be noted that Linux hide files with `.` not as a security mechanism, as anyone with read permission can see them through `ls -a`.
- In most cases Linux uses the hidden functionality for: -
  - Declusterring and keeping the user filesystem clean
  - Hidding user application settings
  - Visual concealment which can also prevent accidental deletion by the user
